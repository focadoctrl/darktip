// COMANDOS
Interface de linha de comando
@darktip.bet — python main.py
$ python main.py plan
Gera o plano semanal completo (14 posts) com temas, formatos e horários. Salvo em posts/weekly_plan.json
$ python main.py generate --type estrategia
Gera 1 post completo (legenda + hashtags + CTA). Tipos: estrategia, educacional, analise, motivacional, noticias
$ python main.py carousel "gestão de banca no esoccer"
Gera roteiro + imagens 1080×1080 do carrossel em media/carousels/. Pronto para upload direto no Instagram
$ python main.py queue
Lista todos os posts na fila aguardando publicação, com tipo, tópico e horário agendado
$ python main.py publish posts/queue/post_xxx.json <image_url>
Publica um post no Instagram via Graph API. Move para posts/published/ após confirmar o media_id
$ python main.py status
Exibe info da conta Instagram (seguidores, posts, bio) e resumo da fila atual
